# Echoes of Ember 0.1.0-alpha

## World 1 Vertical Slice

Explore the complete Verdant Reaches route across four platforming levels, discover optional Ember Veil content, and confront the three-phase Ashen Warden in First Flame Sanctum. Nova has responsive platforming, four power-ups, ranged and stomp combat, checkpoints, interactive terrain, collectibles, secrets, NPC dialogue, local achievements, three campaign slots, keyboard/controller support, and configurable audio/effects/fullscreen settings.

This release candidate uses original procedural placeholder visuals and generated audio. The player distribution excludes developer CLI features. A separate developer flavor includes diagnostics, direct-level launch, and the data-compatible level editor.

## Known limitations

- Worlds 2–4 and their bosses are not authored.
- Production art and final soundtrack replacement remain future content work.
- Physical-controller breadth, subjective audio balance, fullscreen hardware coverage, antivirus behavior, and secondary-machine compatibility require human testing.
- The editor is an internal content-production tool and may need ergonomic refinement.
- Linux distributions can vary in native-library compatibility; only the recorded build host was automated in this phase.
