# Content Decision Log

Status vocabulary: CANON, PROPOSED, OPEN QUESTION, DEFERRED.

## Four major worlds retained

- **Decision:** Structure the full arc as Discovery, Doubt, Revelation, Choice.
- **Rationale:** aligns narrative escalation with Learn, Combine, Adapt, Master.
- **Alternatives:** more smaller regions; episodic hub structure.
- **Status:** CANON direction; later world names remain PROPOSED.

## World 2 uses five normal levels plus boss

- **Decision:** Shardwind Crossing, Mirrored Caves, Observatory of Echoes, Broken Meridian, Prismheart Vault, then Luminous Sentinel.
- **Rationale:** enough runway to teach/test/twist currents without rushing narrative doubt.
- **Alternatives:** four larger levels; separate midpoint encounter.
- **Status:** PROPOSED.

## Ember Currents define World 2

- **Decision:** add authored force fields affecting traversal and selected projectiles/platforms/enemies.
- **Rationale:** extends momentum and interaction while reusing existing powers.
- **Alternatives:** grappling, universal wind physics, vehicle sections.
- **Status:** PROPOSED; prototype required before canon production.

## World 3 uses polarity and a midpoint encounter

- **Decision:** four larger normal levels, Keeper Below midpoint, Hollow Regent boss.
- **Rationale:** polarity benefits from longer adaptive spaces; midpoint paces the historical revelation.
- **Alternatives:** five standard levels; no midpoint boss-like event.
- **Status:** PROPOSED.

## World 4 is nonlinear

- **Decision:** Cinder Gate unlocks three freely ordered branches; all unlock Last Conduit/finale.
- **Rationale:** expresses regional choice and mechanical mastery using existing graph concepts.
- **Alternatives:** fixed linear route; choose-only-one branch.
- **Status:** PROPOSED; all-prerequisite graph semantics need prototype.

## One canonical ending

- **Decision:** Nova gradually decentralizes Ember rather than restoring control or releasing everything instantly.
- **Rationale:** resolves theme through responsible action without a simplistic morality menu.
- **Alternatives:** binary endings; ambiguous non-choice; total release.
- **Status:** CANON direction.

## First Keeper is understandable, not cartoon evil

- **Decision:** central authority genuinely believes control prevented catastrophic instability.
- **Rationale:** gives safety/control its strongest historical argument.
- **Alternatives:** corrupted monster; secret profiteer; mindless machine.
- **Status:** CANON characterization direction; exact origin OPEN QUESTION.

## Ember Veil becomes game-wide secret narrative

- **Decision:** secret exits reveal off-network survival, hidden communities, and suppressed alternatives.
- **Rationale:** makes exploration change understanding rather than only score.
- **Alternatives:** disconnected bonus rooms; alternate ending.
- **Status:** CANON direction; individual later routes PROPOSED.

## Existing power-ups remain relevant

- **Decision:** design later routes around Pulse, Boots, Wing, and Guard; no automatic upgrade ladder.
- **Rationale:** preserves recognizable choices and controls scope.
- **Alternatives:** replace each world; permanent skill tree.
- **Status:** CANON production rule. One or two additions are DEFERRED pending proven gaps.

## Secret Tokens are not shop currency

- **Decision:** consider optional Veil/lore thresholds only.
- **Rationale:** preserves deep-exploration identity and avoids economy scope.
- **Alternatives:** purchases, mandatory gates, cosmetic shop.
- **Status:** PROPOSED use; exact thresholds OPEN QUESTION.

## World 1 wording remains shipped

- **Decision:** treat “Verdant Restored” and hopeful post-Warden dialogue as partial character knowledge.
- **Rationale:** preserves shipped canon while later revelations legitimately recontextualize it.
- **Alternatives:** rewrite achievement/dialogue now.
- **Status:** CANON interpretation; no production changes.

## Full four-world scope approved

- **Decision:** build all four worlds (Milestones C–N) rather than a reduced 1.0.
- **Rationale:** project owner decision, 2026-11-08.
- **Status:** CANON scope.

## Nova speaks in text

- **Decision:** Nova has her own short dialogue lines (`speaker: "Nova"` line nodes) plus selectable responses, shown in the standard text box like every other character. No voiced audio.
- **Rationale:** project owner decision, 2026-11-08; matches classic text-box RPG presentation while letting Nova's Discovery → Choice arc be expressed directly.
- **Alternatives:** silent protagonist with choices only; voiced lines.
- **Status:** CANON. The existing dialogue engine already supports any speaker name; no schema change is required.

## Ember Current prototype result

- **Decision:** retain additive, clamped Current acceleration with explicit target categories and effects-independent arrows.
- **Rationale:** automated runtime, collision, projectile, editor, debug, isolation, and performance evidence supports a reusable system without rebalancing World 1.
- **Status:** READY WITH REVISIONS. Human feel/readability testing is required before exact strength bands or final presentation become canon.
- **Deferred:** spline paths, authored switch links, Current-driven platform bodies, production ambience, and Luminous Sentinel integration.
